# EducaAção - Redução das Desigualdades

## Descrição do Projeto
O **EducaAção** é um projeto prático desenvolvido para a disciplina de Programação Web Front-End (2026_02) do curso de Engenharia da Computação da Universidade Tecnológica Federal do Paraná (UTFPR). 

A aplicação web consiste em uma plataforma de voluntariado projetada para conectar estudantes universitários a jovens de comunidades carentes. O principal objetivo do serviço é atuar diretamente no **ODS 10 (Redução das Desigualdades)**, oferecendo uma ponte para o compartilhamento de conhecimento por meio de mentorias de programação, apoio escolar e workshops preparatórios para o mercado de trabalho.

## Estrutura do Projeto
O repositório está organizado com os seguintes arquivos e diretórios:

* **`index.html`**: Página principal da aplicação. Contém a apresentação do propósito da plataforma, as frentes de atuação para os voluntários e uma galeria de imagens mostrando o impacto na comunidade.
* **`cadastro.html`**: Página contendo o formulário semântico com os campos necessários para o registro de novos estudantes voluntários.
* **`login.html`**: Página de autenticação que permite o acesso dos voluntários cadastrados à plataforma.
* **`style.css`**: Folha de estilos do projeto. Implementa um layout estruturado, com uso do Material Icons, fontes do Google Fonts (Poppins), transições de hover e uma paleta de cores organizadas em variáveis no padrão CSS3.
* **`img/`**: Diretório que armazena todos os assets visuais utilizados nas páginas (banners, logotipos e imagens da galeria).
* **Validações W3C**: Arquivos de imagem (`ValidaçaoCSS.png`, `ValidaçaoIndex.png`, `ValidaçaoCadastro.png`, `ValidaçaoLogin.png`) que comprovam a ausência de erros no código HTML e CSS.

## Tecnologias Utilizadas
* **HTML5**: Estruturação semântica das páginas web.
* **CSS3**: Estilização visual, design de interface e alinhamentos em Grid.
